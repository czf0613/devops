# CI worker 修改规则

继承 [DevOps 规则](../AGENTS.md)。这是安装在构建机的独立程序，不是 `server` 镜像中的协作后台进程。

- 保持 Python 3.14、独立依赖锁和 wheel 发布。构建任务只在 Executor 内执行；服务器不得检出执行用户脚本。
- 工作配置只能保存连接 origin、机器身份、工作路径和标签。身份令牌不输出到日志、不写到命令参数；源码临时令牌不进入构建步骤环境。
- 不移除一次性注册、连接代次、任务租约、持久消息 ACK、序号和完成后清理。未确认开始的 offer 可以重派；开始后失联必须 `lost`，禁止静默自动重跑。
- POSIX 测试实际子进程及父进程管道丢失；Windows 保留 Job Object 所有后代清理。不能以交叉编译、静态检查或 mock 代替未具备平台的真机验收。
- 原生执行仅用于可信代码专用构建机，不宣称 sandbox。新容器/VM执行器复用 Executor 生命周期并显式声明 capability。
- 新增行为做针对性 pytest；协议/认证修改也运行 server 的 CI 测试和真实 Gateway + 本机 worker 验证。测试只使用隔离合成数据，不读取宿主凭据。
